## Использование

```sh
git clone https://github.com/IgorKramar/blog-snippets.git
cd blog-snippets/vm-self-hosting-2026
```

Откройте README нужной части. Имена каталогов стабильны и подходят для ссылок из статей. Текущие вложенные README написаны на английском.

Каждая серия размещается в отдельном каталоге верхнего уровня, каждая статья — в своём подкаталоге. Общей сборки, зависимостей или команды запуска нет. Когда появятся примеры, их требования и команды должны быть описаны рядом с файлами соответствующей статьи.
