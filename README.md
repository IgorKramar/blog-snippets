## Usage

```sh
git clone https://github.com/IgorKramar/blog-snippets.git
cd blog-snippets/vm-self-hosting-2026
```

Open the README for the part you need. Folder names are stable targets for article links. The existing nested READMEs are in English.

Each top-level folder belongs to one series, and each subfolder to one article. There is no shared build, dependency set or launch command. As examples are added, their requirements and commands belong beside the files for that article.
